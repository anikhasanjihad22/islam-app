# Islam App (Stitch Premium Mobile Experience)

Static Tailwind-CSS mockup screens exported from Google Stitch, wired into a
navigable static site and deployed via GitHub Actions to GitHub Pages.

## Pages
- `home_dashboard/`
- `quran_reader/`
- `prayer_times/`
- `duas_library/`
- `99_names_of_allah/`
- `islamic_calendar/`
- `settings/`

## Note
These are **UI mockups only** (Tailwind CDN, no backend/JS logic). Real prayer
times, Quran data, etc. are not wired up yet.
